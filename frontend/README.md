# Contract Intelligence Platform — Frontend Client

Modern web interface for contract ingestion, clause review, semantic search, and grounded document intelligence.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite 8
- **Routing:** React Router 7
- **Styling:** Custom CSS design system with CSS custom properties (dark mode ready)

## Scripts

```bash
# Run local development server (port 5173)
npm run dev

# Build production bundle
npm run build

# Run ESLint linter
npm run lint
```
